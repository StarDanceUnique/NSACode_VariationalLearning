# NSACode_VariationalLearning

This is the code repository for the paper "Noise-strength-adapted approximate quantum codes inspired by machine learning" [arxiv-link](https://arxiv.org/abs/2503.11783). 

Some parts of the code are adapted from [caochenfeng/VarQEC-public](https://github.com/caochenfeng/VarQEC-public), with appropriate modifications for our setting.
